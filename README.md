# Hobby Games Bot

Telegram-бот для подбора настольных игр с поиском по каталогу.

## Возможности бота

### Для пользователей
| Кнопка | Что делает |
|--------|------------|
|  Найти игру по названию | Вводите часть названия — бот ищет в реальном времени через API сайта на котором расположен каталог |
|  Подбор игр через ИИ | Искусственный Интеллект подбирает через ключевые слова подходящие игры из каталога, количество которых > 0 |
|  Подборки |  Готовые варианты настольных игр которые есть в наличии под определённый жанр |
|  О нас  | Краткая информация о магазине |

### Для администратора
| Команда | Что делает |
|---------|------------|
| `/status` | Проверяет подключение и показывает статистику каталога |
| `/relogin` | Принудительно переподключается к CloudShop (если сессия слетела) |


## Структура проекта

```
hobby_games_bot/
├── main.py               # Точка входа
├── bot.py                # Регистрация handlers
├── config.py             # Настройки из .env
├── models.py             # Dataclasses: Game, StockItem
├── constants.py          # Промпты, селекторы, константы
├── handlers/
│   ├── start.py          # /start, "О нас"
│   ├── search.py         # Поиск по названию + пагинация
│   ├── ai.py             # Подбор через Gemini
│   └── admin.py          # /relogin /status /reload /clearcache
├── services/
│   ├── browser.py        # BrowserManager (Playwright + asyncio.Lock)
│   ├── cloudshop.py      # Поиск на сайте (параллельный)
│   ├── gemini.py         # Gemini API (с retry)
│   ├── catalog.py        # Чтение Excel + фильтрация
│   └── ai_cache.py       # Кэш рекомендаций (SQLite)
└── utils/
    ├── keyboards.py      # Клавиатуры и inline-кнопки
    └── formatting.py     # Форматирование текста и пагинация
```

## Установка

```bash
# 1. Клонировать / распаковать проект
cd hobby_games_bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Установить браузер Playwright
playwright install chromium

# 4. Создать файл .env из шаблона
cp .env.example .env
# Заполнить все поля в .env

# 5. Подготовить catalog.xlsx (см. ниже)

# 6. Запустить
python main.py
```

## Структура catalog.xlsx

| A — Название       | B — Жанр      | C — Возраст | D — Игроки | E — Теги         |
|--------------------|---------------|-------------|------------|------------------|
| Каркассон          | стратегия     | 8+          | 2-5        | городостроение   |
| Диксит             | вечеринка     | 8+          | 3-6        | ассоциации, арт  |
| Пандемия           | кооператив    | 10+         | 2-4        | болезни, спасение|

Колонки B–E опциональны — бот работает и с одной колонкой A.  
Первая строка — заголовок, автоматически пропускается.

## Команды администратора

| Команда         | Действие                                 |
|-----------------|------------------------------------------|
| `/status`       | Статус браузера, кол-во игр, модель ИИ   |
| `/relogin`      | Принудительный перезаход в CloudShop     |
| `/reload`       | Перечитать catalog.xlsx                  |
| `/clearcache`   | Очистить кэш ИИ-рекомендаций             |

Добавить себя в ADMIN_IDS в .env (узнать свой ID: @userinfobot).

- **page.close() в finally** — нет утечек страниц браузера
- **split_long_text()** вызывается один раз
